# Mobile design skill in this repository

`SKILL.md` is the entrypoint for mobile UI work in this project. It is scoped to the
Flutter Android/iOS V15 app and defers to the root `AGENTS.md`,
`design-app/mobile-v15/index.html`, and `docs/guias/design-v15.md`.

The files under `references/` are optional upstream examples. Read only a relevant
Flutter reference when the current task needs it; their React Native, SwiftUI, Compose,
web, testing, and visual-invention workflows are not project instructions.

These files already live in the project at `.agents/skills/mobile-design/`. Do not copy
them into a Claude-specific home directory or depend on slash-command installation steps.

# Surface brief — Radar de Benefícios mobile V12

Mode: operate. Scope: Android compact presentation layer and the V12 clickable
reference; preserve the real Flutter route, API data, states and actions.

## Direction contract

THESIS: Make the app read like a working signal instrument: the user scans
quality and next action, not a pile of promotional cards. Refuse the generic
dashboard of equal cards and decorative metrics.

OWN-WORLD: Navy/green paper surfaces, red action marks, teal Inter signals and
green Pichau signals; solid semantic roles, compact system sans, recut corners,
one signal rail and one offset marker. Material 3 behavior remains the native
Android foundation.

STORY: On arrival, the user understands what is active, delayed, partial or
missing; they move to Serviços or a domain, inspect honest API-backed content,
and take the valid action without losing search, filters, page or position.

FIRST VIEWPORT: A compact top app bar names the current context. Início leads
with a single signal summary and three domain rows, each with a colored rail,
state marker and one next action. The two-item compact navigation stays within
thumb reach; dense domain surfaces put search/filter controls before results.

FORM: Candidate 5 from the grounded signal-atlas direction list, assigned by
Impeccable concept seed key e49044c1. The atlas becomes functional through
fixed rails, state markers, domain color roles and a brief scan-line opening;
the literal star chart is not copied as decoration.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
